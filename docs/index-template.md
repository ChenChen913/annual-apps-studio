# 名录模板使用说明

「名录」是一套可长期复用的图片背景索引模板：左侧分类标签，右侧头像网格，最后可以留一个信息站列表。它不绑定 AI 创作者，也可以做播客、工具、书单、公司、活动嘉宾等任意分组名录。

## 1. 两个入口

打开右侧「模板」面板，选择「名录 / INDEX」：

- **载入示例**：载入 66 条 AI 创作者 / 官号 / B 站老师 / 播客与信息源，适合直接改。
- **空白名录**：保留背景、标题、字号、分类栏和导出尺寸，但清空所有分类与条目；从零开始建自己的名录。

两个入口都会切到当前背景「雾锁林间」。之后在「内容」面板编辑即可，改动会自动保存到当前项目。

## 2. 增减分类

「内容」面板 → 「分类与条目」：

- **添加分类**：点底部「添加分类」，新分类默认叫「新分类」，直接在分类名输入框改名。
- **删除分类**：分类右上角垃圾桶；空分类可以直接删，有内容时会二次确认。
- **调整顺序**：分类右上角上下箭头，决定海报上的分类从上到下的顺序。
- **新增「AI 播客」**：点「添加分类」→ 改名为「AI 播客」→ 添加条目并上传播客封面即可；不需要改代码。
- **新增「B 站老师阵营」**：同样新建分类，条目名可以是老师姓名，也可以是 `Stanford CS229`、`MIT 6.S191` 这类课程；老师没有官方 B 站号时，头像优先用个人官网 / 学校官方页 / 公开职业照，课程可用校徽或课程官方标识。
- **删除「AI 信息站」**：直接删掉该分类；模板会自动把信息站列表收起，不会留下空行。

## 3. 增减条目

- **添加条目**：分类底部「添加条目」→ 从图标库选一个，或上传本地图片（建议 1:1、≥ 512px）→ 填名称。
- **替换头像**：点条目左侧小图 → 上传本地头像，或在线搜索图标。
- **排序**：拖动条目左侧手柄；可以拖到同一分类任意位置，也可以拖到别的分类。
- **改名 / 删除**：条目右侧输入框直接改名；垃圾桶删除，可撤销。

## 4. 信息站网址

分类 id 为 `ai-sites`，或分类名包含「信息站 / 网站 / 网址」时，模板会把该分类渲染成底部信息站列表：

- 每个信息站左侧是圆形图标，右侧第一行是名称，第二行是网址。
- 网址来自该条目的「备注」字段；在内容面板里，这类分类的备注标签会显示为「网址」，直接填 `www.reddit.com`、`github.com/trending` 即可；原站有 `www.` 就保留，没有就不补。
- 网址和名称都在导出图里，不是只存在于项目文件中。

## 5. 版式微调

「模板」面板下方「排版」可以调：

- 每行图标数、图标大小、横向/纵向间距、起始位置、标题字号、分类字号、名称字号。
- 「适配当前画幅」会按当前内容重新计算间距，避免溢出。
- 背景可在「背景」面板更换，或使用自定义图片。

## 6. 导出

右上角选择 `PNG / JPG / WebP` 与倍率。名录模板推荐 `4:5 · 3×`（4800×6000）；预览用 1× 即可。

- 分类 / 条目编辑：`src/components/panels/ContentPanel.tsx`
- 头像核对经验：`docs/avatar-sourcing.md`

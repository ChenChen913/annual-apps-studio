# 我的年度软件 · 海报编辑器

把这一年的软件做成一页可编辑海报。内置 **13 套模板 × 6 种画幅 × 67 张背景 × 115 个软件图标**，所有内容都在浏览器里改，导出 PNG / JPG / WebP，断网也能用。

> 素材来源与许可见 [ASSETS_LICENSE.md](./ASSETS_LICENSE.md)。代码与素材的许可**分开处理**。

---

## 功能

### 排版与模板

- **名录模板可编辑**：载入示例后可在「内容」面板增删分类、改名、换头像、调顺序；信息站分类会自动显示名称 + 网址，网址保留 `www.` 原始写法。头像与站点图标的核对流程见 [`docs/avatar-sourcing.md`](docs/avatar-sourcing.md)。
- **13 套模板**：雅致、**名录**、像素、可爱、杂志、极简、赛博、手账、新粗野、终端、Y2K、电影、报纸。每套有独立的排版语言（杂志的编辑式分栏、终端的等宽字体与两段式信息区、手账的胶带与便签、电影的全幅主视觉等），不是同一套卡片换配色。**名录**是图片背景的索引式大海报：左侧分类标签、右侧头像网格，装下 66 位 AI 创作者 / 官号 / B 站老师 / 播客与信息源；支持载入示例或新建空白名录，分类、条目、信息站网址都可增删改，详见 [`docs/index-template.md`](docs/index-template.md)。
- **6 种画幅**：16:9（1600×900）、4:5（1600×2000）、3:4（1200×1600）、1:1（1600×1600）、9:16（1080×1920）、2:3（1200×1800）。切换画幅会按画布重新推导列数、图标尺寸、行距与起始位置，竖版不会再被压回横版参数。
- **模板 × 画幅联动**：每套模板在每个画幅下有独立的默认布局；手动调过的参数在切换模板时按明确规则重置（见「行为约定」）。
- **导出预设**：小红书、朋友圈、手机壁纸、高清横图、方图，一键切换画幅 / 倍率 / 格式。

### 内容

- **分类与软件**：增删改、上下排序、拖拽排序、跨分类移动。
- **图标**：115 个内置图标（按 AI / 浏览器 / 开发 / 办公 / 设计 / 媒体 / 效率 / 系统分类），支持中文名、英文名、别名与关键词搜索；可收藏、看最近使用；也可上传本地图片（PNG / JPG / WebP / SVG）。
- **在线搜索**：需要时手动触发，走 Iconify 公开 API，命中后可「仅本次使用」或存入「我的图标库」。
- **评分 / 备注 / 标签**：每个软件可评分、写备注、加标签，部分模板会在海报上展示。

### 背景

- **67 张背景**，分六个族：自然（雪山、森林、海洋、日出日落、云、沙漠、城市夜景、雾）、抽象（Mesh 渐变、液态玻璃、液态大理石、液态金属、胶片颗粒）、科技（发布会舞台、深蓝粒子、光轨）、极简（纸张、棱镜焦散、留白）、人物、经典（3 张原有默认背景）。
- **背景调整**：缩放（100–200%）、水平位置、垂直位置、模糊（0–24px）、背景浓度、压暗、叠色（含强度）、一键重置。全部是滑块，没有引入图片编辑器。
- **这些参数参与导出**：预览层与导出层共用同一套几何计算，导出结果与预览像素级一致（校验脚本测得平均差 0.13/255）。

### 数据与离线

- **自动保存**到 IndexedDB，刷新后画幅、模板、标题、背景参数全部恢复。
- **草稿箱**：最多 20 份手动存档，同名覆盖；恢复时同样过一遍数据校验，旧版本草稿缺字段会自动补默认值。
- **项目文件**：导出为单个 `.yearapps`（JSON），可再次导入；导入时校验结构、颜色、背景引用与旧版本字段。
- **PWA**：生产构建可安装，首次加载后离线可用。
- **离线边界**：模板、背景、内置图标、字体全部本地加载；只有「在线搜索图标」需要网络，不联网不影响编辑、保存与导出。

| 层 | 选型 |

## 本地运行

```bash
npm install
npm run dev          # http://localhost:5173
```

构建与本地预览生产版本：

```bash
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

```bash
npm run lint         # oxlint
npm run test         # vitest run
npm run build        # tsc -b + vite build
```

- [2026-我的年度软件.html](./public/standalone/2026-我的年度软件.html)：原有 20 个软件版本，保留作对照。

## 背景素材

| 类别 | 数量 | 来源 | 许可 |
| --- | --- | --- | --- |
| 自然摄影 | 20 | Wikimedia Commons（逐张人工挑选） | CC0 1.0 |
| 抽象 / 科技 / 极简设计 | 10 | 本项目生成（Mesh 渐变 / 液态玻璃 / 液态金属 / 发布会舞台 / 棱镜等） | 随项目发布 |
| 原有默认背景 | 3 | 项目早期素材，保留原构图，本地放大到 3840px | 随项目发布 |
| 程序绘制 | 33 | CSS 渐变 / SVG / 噪点，本地生成 | 无第三方素材 |

- 实拍与设计背景统一为长边 3840px WebP（质量 82），另配长边 720px 缩略图；整包约 26 MB。导出 9:16 长图按 2× 也不会把背景上采样放大。
- 全部放在 `public/backgrounds/`，**不依赖任何第三方图床**。
- 每张图的作者与来源页写在 `src/data/backgrounds.ts` 的 `PHOTO_LIBRARY`，UI 会在背景详情里显示署名与素材页链接。
- 新增或替换背景的流程：选素材（原始长边 ≥ 3840px）→ 核验许可 → 转 3840px WebP + 720px 缩略图 → 写入 `PHOTO_LIBRARY`（含 provider / title / pageUrl / license / artist）→ 同步更新 `ASSETS_LICENSE.md`。

内置 115 个图标按类别组织，全部为本地 WebP，运行时不请求网络：

| 来源 | 数量 | 许可 |
| --- | --- | --- |
| SVG Logos（Iconify） | 55 | CC0 1.0 |
| Dashboard Icons（homarr-labs） | 27 | Apache-2.0 |
| Devicon（Iconify） | 17 | MIT |
| 项目原有品牌图稿 | 15 | 版权归各品牌，仅作识别用途 |

- 品牌图标保持原始配色与造型，不做统一着色，避免破坏品牌识别。
- 在线搜索走 `https://api.iconify.design`（CORS 开放、无需密钥），只读接口，不抓页面、不嵌 iframe。
- 白名单集合：`logos`（CC0）、`simple-icons`（CC0）、`devicon`（MIT）、`selfhst`（CC BY 4.0，对外发布需署名）。
- 在线搜到的图标会被栅格化成 320px WebP 再存入本地，确保之后断网仍可显示。
- **不接入** macOSicons 与 Windows Icon Archive：两者都没有可靠的公开接口，站点条款也不允许批量抓取。
- 公共内置库是**运行期只读**的：要新增内置图标，把 320×320 的 WebP 放进 `public/icons/`，在 `src/data/icons.ts` 里补一条（分类、平台、中英文关键词、来源、许可），再同步更新 `ASSETS_LICENSE.md`。界面上只能「存入我的图标库」（本机 IndexedDB），不会改动公共库。

## 导入导出

- **项目文件**：`.yearapps`，内容为 `{ schemaVersion, doc }` 的 JSON。`schemaVersion` 当前为 `3`。
- **导入校验**：解析 → 结构校验 → 缺失字段补默认 → 数值按当前画幅的合法范围收敛（非法值仍会被限制，不会原样放行）。
- **旧版本兼容**：
  - `schemaVersion` 缺失或为 1/2 时，补齐背景调整字段（`bgZoom` / `bgX` / `bgY` / `bgBlur` / `bgOpacity` / `bgTint` / `bgTintOpacity`）与布局字段后按 v3 载入。
  - IndexedDB 里的旧文档（`annual-apps-studio-v2`）在 rehydrate 时走同一个 `sanitizeDoc`，刷新不会丢布局。
  - 草稿恢复同样走校验：旧草稿缺背景参数字段时补默认，不会出现 `undefined` 导致背景层错位。
- **导出图片**：PNG / JPG / WebP，倍率 1/2/3。导出使用与预览相同的布局与背景几何；JPG 会铺白底，PNG / WebP 走画布自身的背景色。
- **导出项目**：在「项目」面板里导出 `.yearapps`，包含自定义图标与自定义背景（以 data URL 内联），可在另一台机器导入。

## 行为约定（容易踩的点）

- **切换模板**：保留标题、分类、软件与背景选择，按新模板 + 当前画幅重新推导布局参数；手动改过的 `columns` / `iconSize` / `gapY` 等会被重置，避免把 A 模板的间距带到 B 模板。
- **切换画幅**：同上，按新画布重排；背景缩放与位置按百分比语义保留，不会因画幅变化而错位。
- **参数范围**：每个画幅的 `gapY` / `startY` / `iconSize` / `gapX` 上下限由画布尺寸推导（`getLayoutBounds`），不是全局固定值——竖版允许更大的行距和更靠下的起点。
- **撤销 / 重做**：上限 50 步；同一控件 700ms 内的连续改动合并为一步（拖滑块不会产生上百条历史）。

## 已知限制

- 9:16 等窄画幅下，部分模板（可爱、手账、杂志、报纸）为了保留风格化留白，行距偏大，软件数量多时会出现明显空白。
- 内置 115 个图标覆盖常用 AI / 开发 / 办公软件，但并非全量；小众桌面软件需要用户自行上传。
- 3 张原有默认背景（林间夜灯、海湾暮色、城市夜眺）已恢复原构图；原图仅 1600×900，本项目在本地用 Lanczos 放大到 3840×2160 并做了轻度锐化（未重绘），细节不会凭空增加。
- 在线搜索依赖 Iconify 可用性；服务不可用时只影响该功能，不影响编辑与导出。

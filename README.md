# 我的年度软件 · 海报编辑器

把这一年的软件做成一页可编辑海报。内置 12 套模板、36 张背景、6 种画幅，所有内容都能在浏览器里改，导出 PNG / JPG / WebP。

## 功能

- **12 套模板**：雅致、像素、可爱、杂志、极简、赛博、手账、新粗野、终端、Y2K、电影、报纸
- **36 张背景**：实拍照片与本地生成的渐变、风景、人物、抽象背景，支持分组和搜索
- **6 种画幅**：16:9、4:5、3:4、1:1、9:16、2:3，切换画幅自动重排
- **内容编辑**：分类和软件增删改、上下排序、拖拽排序、跨分类移动、图标替换与上传
- **评分 / 备注 / 标签**：每个软件可评分、写备注、加标签，部分模板会在海报上展示
- **草稿箱**：最多 20 份手动存档，支持载入、删除、清空
- **导出预设**：小红书、朋友圈、手机壁纸、高清横图、方图，一键切换画幅 / 倍率 / 格式
- **PWA**：生产构建可安装到桌面，首次加载后支持离线编辑和导出
- **本地优先**：自动保存到 IndexedDB，项目可导出为单个 `.yearapps` 文件

## 本地运行

```bash
npm install
npm run dev
```

## 构建与离线预览

```bash
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

Service Worker 只在生产构建注册。首次加载后等待几秒，即可在浏览器菜单中安装，断网后仍能打开。部署到线上时需要 HTTPS。

## 技术栈

Vite + React + TypeScript + Tailwind CSS + Zustand + idb-keyval + modern-screenshot。

## 说明

- 图标为 512×512 的官方图稿，统一裁切并生成 squircle 蒙版，透明边缘只乘 alpha，避免黑边。
- 背景除三张实拍照片外，均由 CSS / SVG 在本地生成，不依赖外部图床。
- 字体使用本地霞鹜文楷 WOFF2，断网可用。
